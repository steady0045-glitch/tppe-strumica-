ТППЕ СТРУМИЦА — НЕЗАВИСНА ДЕСКТОП / ТВ ВЕРЗИЈА

ПОСТАВУВАЊЕ
1. Во GitHub репото tppe-strumica- постави ја целата папка "desktop" во коренот, на исто ниво со мобилниот index.html.
2. Постави ја папката desktop со сите внатрешни папки: css, js и icons.
3. Не заменувај и не бриши ништо од коренот на мобилната апликација.
4. Десктоп верзијата се отвора на: https://steady0045-glitch.github.io/tppe-strumica-/desktop/
5. ТВ режим: https://steady0045-glitch.github.io/tppe-strumica-/desktop/?tv=1

НЕЗАВИСНОСТ
- Сопствени index.html, CSS, JavaScript, manifest, service worker, кеш и икони.
- Посебен service-worker scope /desktop/ и кеш-префикс tppe-desktop-.
- Посебен localStorage кеш и посебно зачувано име за десктоп чатот.
- Мобилните датотеки и кешот не се менуваат.
- Firebase проектот намерно е заеднички за да се споделуваат податоците меѓу двете верзии.

СТАТУС „НА ТЕРЕН“
- Двоен клик на име во Дежурни / Приправни / Наредна / Слободни го означува со бела боја.
- Повторен двоен клик го враќа во оригиналната боја на неговата смена.
- Статусот се синхронизира преку appdata/fieldStatuses, исто како во мобилната апликација.
- Сите корисници што имаат пристап до Firebase документот го гледаат статусот.

ПОДАТОЦИ
- Заеднички Firebase проект и постојни патеки appdata/main и chatMessages.
- Статусите „На терен“ се во appdata/fieldStatuses.
- Десктопот ги зачувува своите локални поставки одделно и не го препишува мобилниот кеш.
