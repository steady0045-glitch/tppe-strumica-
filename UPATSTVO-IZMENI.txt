ТППЕ СТРУМИЦА – НОВИ ИЗМЕНИ (v4)

АДДЕНИ ФУНКЦИИ:
- Алармот може да се активира и деактивира од ADMIN и KOLEGI, без PIN.
- Состојбата на алармот се чува одделно во Firestore: alarmState/current. Ова спречува колегијалската верзија да ги менува другите администраторски податоци.
- Во LIVE CHAT секој корисник може да избрише порака; бришењето се синхронизира кај сите.
- Додадено е копче „Активирај звук“ со краток тест-сигнал и пуштање на сигнали што чекале дозвола од прелистувачот.
- Телефонските броеви и имињата во составот користат tel: линкови за стандардната телефонска апликација во Windows.
- Service worker cache е обновен на v4.

ПОТРЕБНИ FIRESTORE RULES:
Интегрирај ги следните правила во постојните Firestore Rules (не ги заменувај другите правила ако веќе имаш дополнителни колекции):

match /alarmState/current {
  allow read, create, update: if true;
  allow delete: if false;
}
match /chatMessages/{messageId} {
  allow read, create, delete: if true;
  allow update: if false;
}

ВАЖНО:
- Правилата погоре дозволуваат секој што ја користи апликацијата да го менува алармот и да брише која било порака во чатот, како што е побарано.
- Чатот прикажува име внесено од корисникот. Бидејќи моментално нема Firebase Authentication, името не е проверен идентитет.
- Јавното дозволување на аларм е намерно побарано. Подоцна може да се додаде лична најава и ограничување по кориснички профили.

ЗВУЧНИ ИЗВЕСТУВАЊА:
- При отворање се проверува дали има соопштение или активен аларм.
- Chrome/Windows/Android може да блокира автоматско пуштање звук без претходна интеракција. Притисни „Активирај звук“ еднаш во апликацијата; ќе се пушти краток тест-сигнал и ќе се активираат сигналите што чекаат.
- Звукот работи додека апликацијата е отворена. За известувања кога е целосно затворена е потребен посебен Web Push серверски механизам.

ПОВИКУВАЊЕ ОД WINDOWS:
- Отвори Settings > Apps > Default apps > Choose defaults by link type.
- Пронајди TEL и избери MicroSIP, Linphone, Skype или друга апликација што го поддржува TEL.
- Клик на број или име во апликацијата ќе ја отвори стандардната TEL апликација. Дали повикот почнува веднаш зависи од избраната апликација и нејзините поставки.
- Ако MicroSIP не се појавува за TEL, провери дали ја регистрира TEL шемата во Windows; некои SIP поставки бараат посебен SIP URI/handler.

ПОСТАВУВАЊЕ:
- Направи резервна копија од тековниот Netlify deploy.
- Распакувај го ZIP-от и постави ја содржината на соодветната папка admin или kolegi на истата Netlify страница.
- Не ги менувај Firebase конфигурациските податоци.
